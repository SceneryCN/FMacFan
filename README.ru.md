# MacFan

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md)

Компактное нативное приложение для управления вентиляторами Mac с Apple Silicon
на macOS 13 и новее.

## Возможности

- Независимые настройки левого и правого вентилятора
- Автоматический режим, фиксированная скорость и температурная кривая
- Переключатель запуска при входе в панели строки меню
- Нативный SwiftUI без веб-среды выполнения
- Адаптивный редкий опрос и оптимизированные по размеру сборки
- root Helper с проверкой подписи XPC-клиента
- Пятисекундная защита от потери связи и аварийная максимальная скорость

В MacBook Air и других моделях без вентиляторов управлять нечем. Доступные
датчики и поведение SMC зависят от поколения устройства.

## Установка из DMG

1. Скачайте `MacFan-<version>-arm64.dmg` со страницы Releases.
2. Откройте DMG и перетащите MacFan в папку «Программы».
3. Сборки GitHub имеют временную подпись и не нотарифицированы Apple. Перед
   первым запуском выполните:

```shell
xattr -cr /Applications/MacFan.app
open /Applications/MacFan.app
```

Если macOS сообщает о недостаточных правах, выполните только удаление карантина
с правами администратора:

```shell
sudo xattr -rd com.apple.quarantine /Applications/MacFan.app
```

Не отключайте Gatekeeper глобально. По запросу macOS разрешите Helper MacFan в
«Системные настройки → Основные → Объекты входа».

## Сборка

Требуются Mac с Apple Silicon, macOS 13 или новее и актуальная полная версия
Xcode. XcodeGen нужен только для повторной генерации проекта.

Откройте `MacFan.xcodeproj`, выберите схему MacFan и команду разработчика.

```shell
xcodegen generate
```

При отправке тега `v*` GitHub Actions собирает приложение arm64, применяет
временную подпись, создаёт сжатый DMG и SHA-256, затем прикрепляет их к Release.

## Безопасность

Скорость ограничивается диапазоном RPM, сообщаемым оборудованием. При ошибке
датчика, сбое Helper, потере связи или выходе из приложения управление
возвращается системе. При аварийной температуре вентиляторы сразу переходят
на максимальную скорость.
